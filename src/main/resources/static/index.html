About FoodHub

Overview

FoodHub is a comprehensive web-based real-time information system designed for Batangas State University (Alangilan Campus) cafeteria stalls. The platform enables students to easily browse stall menus, check availability, view seating arrangements, and provide feedback. Stall administrators can efficiently manage their menus, update stall status, and track occupancy in real-time.

Key Features

  • Real-time stall status and menu availability
  • Interactive seating map with seat availability tracking
  • Student feedback and rating system
  • Admin portal for stall management
  • Search and filter functionality for menus and stalls
